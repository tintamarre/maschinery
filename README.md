# Maschinery

A browser pad instrument inspired by the Native Instruments Maschine Mikro MK3. Vue 3 + Vite + Tailwind + Web Audio API, hosted on GitHub Pages.

## Développement

```bash
npm install
npm run dev
npm run build
```

Déploiement : push sur `main` → workflow GitHub Pages (`.github/workflows/deploy.yml`). Activer Settings → Pages → Source: GitHub Actions.

## Roadmap

1. 16 pads, sons synthétisés, clavier + tactile (fait)
2. Kits d'échantillons
3. Séquenceur 16 pas, tempo, swing
4. Enregistrement live avec quantification
5. Web MIDI + potards
